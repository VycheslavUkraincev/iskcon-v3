## Известные дефекты (бэклог преданных на 22.10.2026)
Список взят из старого CLAUDE.md. Какие пункты закрыты срезами 0–8.5 в `iskcon-cv-ua`, в v3 не отслеживается (`STATUS_PLAN.md` остался там). Перед работой над пунктом проверять его по коду, не считать актуальным по этому списку.
- P0: логотип «Їжа життя» обрезан контейнером и не переводится (корень: растр с вшитым текстом). Решение: солнце-SVG + подпись HTML-текстом из i18n. НЕ «3 файла логотипа».
- P0: hero главной: массивная двухъярусная шапка, текст на пёстром фото алтаря (контраст < AA). Решение: шапка в один ряд + редакционный split или scrim, контраст ≥4.5:1.
- P0-заблокировано: Google-формы Анади Кришны (курсы, волонтёры) — URL нет. Кнопку «Стати волонтером» (сейчас href="#") не выдумывать; делать точки подключения data-form.
- P1: центрирование блоков по единой сетке; выровнять фото алтаря (горизонт ≤0.3°); плавающий виджет мантры не перекрывает контент; ~15+ МБ неиспользуемых медиа — удалять только по подтверждённому списку.
- Отзывы давали преданные общины (инсайдеры). Приёмка двухконтурная: преданные (факты/полнота) + тест новичка за 5 секунд.

## Дизайн (кратко из DESIGN.md)
Основная палитра сайта — тёплая бумага. «Грозовая туча» — не основная тема, а палитра только тёмных сцен внутри тёплого сайта (решение от 27.10.2026). Токены и подробности — в `DESIGN.md`.
- Палитра: бумага #FBF6ED, чернила #2B2117, шафран #D98E1F / текст #96570C, туласи #3F5D49, CTA терракота #B0512F. Тёмные сцены — «Грозовая туча»: фон #0F172A, карточки #1E293B, текст #F1F5F9, акцент #E9A23B; золото #C9A24B только на тёмном. Без градиентов (кроме scrim), без glassmorphism, без сине-фиолетового; исключение — сланцево-тёмный фон сцен «Грозовой тучи».
- Шрифты: Spectral (заголовки/цитаты), Onest или Inter (текст); кириллица обязательна, проверять Ґ Є І Ї. Marck Script — 1–2 слова акцента.
- Сетка: контейнер 1200, мера 720, ритм секций clamp(64px,10vw,128px); радиусы 6/10/999; арочный кроп фото 999px 999px 6px 6px.
- Motion: CSS ease запрещены; cubic-bezier(.16,1,.3,1) и (.65,0,.35,1); 250/450/800 ms. Один signature-эффект: «Дыхание алтаря» (GSAP ScrollTrigger, scrub). prefers-reduced-motion — статика.
