# AGENTS.md — iskcon-v3

Для Codex и других агентов. Перед работой прочитать:

- `CLAUDE.md` — правила проекта, инварианты, порядок работы;
- `DESIGN.md` — дизайн-токены и правила;
- `MEDIA.md` — инвентарь медиа и правила использования.

Правила:

- Работать только внутри папки этого проекта. Не читать и не менять файлы вне неё, в том числе соседние репозитории (`iskcon-cv-ua`, `iskcon-v2`).
- Публикация (push, GitHub Pages, превью, деплой на живой домен iskcon.cv.ua) — только по слову владельца.
- Факты не выдумывать: тексты, цифры, контакты, реквизиты, отзывы берутся только из репозитория. Нет данных — спросить или оставить явный плейсхолдер.
- Инварианты из `CLAUDE.md` (URL, якоря, расписания, контакты, платёжные данные, ключи словаря) без согласования владельца не менять.
- Лица людей не генерировать.
- Логотип и QR-коды не менять и не перерисовывать.
