# AUDIT.md — глубокий аудит существующего сайта iskcon-v3

**Дата:** 27.10.2026 · **Ветка:** `design/claude` (от `a7b207b`) · **Режим:** только чтение. Файлы сайта не менялись. Единственная правка в репозитории вне новых документов и папки `mockup/` — строка `.screenshots/` в `.gitignore`, по согласованию владельца.

**Как проверялось.** Своим сервером предпросмотра, который раздаёт файлы прямо из папки варианта и срезает префикс `<base href="/iskcon-cv-ua/">` (`~/scratch/claude-audit/serve.mjs`, без симлинка). Инструменты:
- Node-Playwright 1.64.1 + Chrome 156;
- axe-core 4.14.0;
- Lighthouse 13.5.0, mobile и desktop;
- sharp 0.35.5: свой замер контраста по пикселям;
- jsqr 1.4.0: расшифровка QR.

Скрипты лежат в `~/scratch/claude-audit/` (`static-audit.mjs`, `runtime-audit.mjs`, `qr.mjs`, `glyphs.mjs`), скриншоты 375/768/1440 — в `.screenshots/audit/` (не коммитятся). Старый репозиторий `iskcon-cv-ua` читался только через GitHub API (ветка `mockup-v2-docs`), без правок и без копирования отчётов: из него взяты только факты для сверки — реестр соцсетей и видео, отзывы преданных, структура задания на аудит.

## 1. Резюме

Сайт v3 (снимок `mockup-v2`) технически здоров:
- axe не нашёл ни одного нарушения на 5 страницах при 375 и 1440;
- Accessibility в Lighthouse — 100 везде;
- горизонтального скролла нет, ошибок в консоли нет;
- перевод EN/RO на живом DOM полный (0 кириллических узлов);
- все инварианты на месте, QR расшифровываются в правильные платёжные ссылки.

Главные проблемы лежат не в коде, а в публикации, медиа и документах.

**5 главных проблем**
1. **Живой домен показывает старую версию.** iskcon.cv.ua отдаёт версию до макета: Playfair Display, эмодзи в H1 «🙏 Меценати храму», инлайн-стили. Всё, что исправлено в v3, посетитель не видит.
2. **Плавающий виджет мантры перекрывает текст** на мобильном. При прокрутке на 375 он пересекает абзацы: главная — 22 пары «виджет / текст», `/donation` — 8, `/courses` — 5, `/food` — 5.
3. **31 МиБ медиа без ссылок** (85 файлов из 293, 47 МиБ всего) плюс мёртвый код `guide.js`/`guide.css`.
4. **Мобильная производительность 84–87.** LCP 3,8–4,3 с; render-blocking — 600–740 мс (CSS 84 КБ, из них ~55–65 КиБ не используются на странице).
5. **Документы расходятся с кодом.** Словарь — «~820 пар» против 584/582; шафран; туласи; Inter/Onest. Плюс происхождение фото курсов не подтверждено.

**5 главных сил**
1. Контент полный и честный: расписания, FAQ, реквизиты, фото общины. Отзывы преданных это подтверждают (F9).
2. Первый экран главной уже прошёл исправления: шапка в один ряд (61–65 px), текст на фото под скримом — контраст по пикселям ≥ 5,7:1.
3. i18n работает на всём DOM, включая alt и aria-label; логотип «Їжа життя» теперь SVG + HTML-текст и переводится.
4. Доступность: skip-link, видимый фокус, меню открывается и закрывается с клавиатуры, при `prefers-reduced-motion` GSAP не грузится и анимаций нет.
5. Дубли `*.html` и `*/index.html` побайтно одинаковы; canonical ведёт на папочные адреса.

## 3. По 12 блокам задания

1. **Карта и дубли.** 9 HTML: `index.html`, `courses.html` = `courses/index.html`, `food.html` = `food/index.html`, `donation.html` = `donation/index.html` (побайтно одинаковы), `404.html` (`noindex`). Canonical — папочные адреса. `robots.txt`: `Allow: /` + sitemap живого домена. `sitemap.xml`: 4 папочных URL. Сервер предпросмотра: `/courses` → 301 → `/courses/`, несуществующий адрес → 404 с `404.html`.
2. **Мёртвые CTA.** `href="#"` — 0. `data-form` — 3: `courses` → `#courses-list` (**blocked**, нет URL), `ffl-volunteer` → Google-форма (есть), `feedback` → Google Maps.
3. **i18n.** `i18n.js` прочитан полностью (165 строк). Перевод по текстовым узлам и атрибутам `alt/title/aria-label/data-caption/placeholder` + meta. `MutationObserver` отключается на время перевода. Язык — из `?lang=` или `localStorage`, без автоопределения. Живой DOM: 0 непереведённых узлов в EN и RO на всех 5 страницах. Словарь — 584 RO / 582 EN.
4. **Платежи, контакты, соцсети.** Всё на месте, QR расшифрованы — см. FACTS.md. Форма записи на курсы — blocked.
5. **Медиа и производительность.** См. P1-2, P1-3, P1-5. Аватар: 4 сцены `avatar-{main,food,learn,donate}.webm` (0,6–1,5 МБ), имена собираются динамически (`avatar.js:39–47`), при reduced motion — неподвижный постер.
6. **SEO и мета.** На всех страницах есть title, description, OG, Twitter и canonical. `hreflang` только из JS (P2-1). `og:image` указывает на живой домен.
7. **Доступность.** axe (WCAG 2.0/2.1/2.2 A и AA): 0 нарушений. Skip-link есть. Фокус — `outline: 2px solid`. Меню: Enter открывает, Escape закрывает и возвращает фокус (все страницы, 375). Тач-цели < 24 px: только skip-link 1×1 в покое (появляется по фокусу — норма). reduced motion: GSAP не грузится, 0 запущенных анимаций, 0 играющих видео.
8. **UX и мобайл.** Шапка 61 px (375/768) и 65 px (1440), один ряд. Горизонтального скролла нет. Виджет мантры — P1-1. Скриншоты: `.screenshots/audit/{home,courses,food,donation,404}-{375,768,1440}.png` и `-full.png`, плюс EN/RO 1440.
9. **Дизайн-критика.** Не проводилась инструментами `impeccable`: в этой ветке макет делается с нуля, а не правкой текущего. Наблюдения по текущему дизайну вошли в DESIGN-PROPOSAL.md как причины решений.
10. **Код и долг.** `style.css` 84 КБ, 1131 строка, старый блок до строки 370 («Срез 2») ≈ ⅓. `guide.js`/`guide.css` не подключены нигде. Инлайн: главная — 1 `style=` (iframe карты), 1 JSON-LD; `/food` — 1 инлайн-скрипт. Внешних шрифтов нет (self-hosted Spectral/Onest). Ошибок в консоли нет.
11. **Безопасность и приватность.** Ссылок `target="_blank"` без `rel="noopener"` — 0. Iframe: Google Maps (`loading="lazy"`), WayForPay `#donateFrame` (`allow="payment"`, без `sandbox`). YouTube подключается только по клику через `youtube-nocookie.com` (`food.js:72–78`). Ключей и токенов в коде нет.
12. **Живой сайт против репозитория.** См. P0-1. Зеркало `vycheslavukraincev.github.io/iskcon-cv-ua/` отвечает 200 (содержимое построчно не сверялось).

### Контраст текста на фото (отдельно, по пикселям)

axe помечает `color-contrast` как **incomplete**: главная — 8 узлов на 375 и 10 на 1440, `/food` — 4. Причина в выводе axe: «background color could not be determined due to a pseudo element» — фон hero состоит из фото и скрима на псевдоэлементе, и axe его не вычисляет.

Поэтому контраст замерен своим скриптом на sharp: текст первого экрана делается прозрачным, снимается фон, под **прямоугольником самого текста** (Range) считается контраст каждого второго пикселя, в зачёт идёт 5-й перцентиль.

| Страница | Ширина | Самый слабый текст | p5 | Порог |
|---|---|---|---|---|
| Главная | 1440 | надзаголовок «Чернівці · ІСККОН» на фото | 5,83 | 4,5 |
| Главная | 1440 | H1 на фото (минимум 8,87) | 11,61 | 3 |
| Главная | 375 | «Прийти в неділю» | 5,17 | 4,5 |
| /food | 375/1440 | «Підтримати», «Благодійна місія» | 5,17 | 4,5 |
| /courses, /donation, 404 | все | — | ≥ 5,17 | 4,5 |

Итог: P0 «текст на фото < AA» из старого бэклога **в коде закрыт**.

Граница метода: замер сделан в верхней точке прокрутки. Свет «дыхания алтаря» меняется при скролле. По DESIGN.md он лежит под скримом, но на других позициях прокрутки это не замерялось.

Две ошибки метода найдены и исправлены по ходу:
- `-webkit-text-fill-color` перекрывал `color: transparent`;
- бордюр кнопки попадал в рамку элемента.

## 6. Бэклог для макета (без дублей, по срезам)

1. **Hero главной:** текст не на фото (решено в макете сплитом), виджет мантры — в потоке, а не поверх.
2. **Главная:** одна основная кнопка на экран; галерея без «кирпичей» с неверными размерами (P1-5); происхождение фото курсов (P1-4).
3. **Courses:** форма записи — точка `data-form="courses"`, URL blocked.
4. **Food:** сохранить видео как блок доверия; проверить RO/EN-значения.
5. **Donation:** реквизиты и QR неприкосновенны (проверено jsqr).
6. **Сквозное:** медиа (P1-2), CSS (P1-3), `hreflang` (P2-1).
